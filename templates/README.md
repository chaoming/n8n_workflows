# Workflow Templates

This directory contains basic templates to help you get started with creating new workflows.

## Using Templates

1. Copy a template file
2. Import it into n8n
3. Modify it to suit your needs
4. Export and save to the appropriate category

## Available Templates

- `workflow-template.json` - Basic workflow template with a start node

## Creating Your Own Templates

Templates should be minimal and reusable. Include only the essential structure and common nodes that are frequently used across similar workflows.
