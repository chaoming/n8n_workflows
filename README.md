# n8n Workflows Collection

Welcome to the n8n Workflows Collection! This repository contains a curated collection of useful n8n workflows for various automation tasks.

## 📖 About n8n

[n8n](https://n8n.io/) is a free and open-source workflow automation tool. It allows you to connect various services and automate tasks without writing code (or with code if you prefer).

## 🗂️ Repository Structure

```
n8n_workflows/
├── workflows/          # All workflow files (.json)
│   ├── productivity/   # Productivity automation workflows
│   ├── social-media/   # Social media automation workflows
│   ├── data/          # Data processing workflows
│   └── notifications/  # Notification workflows
├── templates/         # Workflow templates
└── docs/             # Documentation and guides
```

## 🚀 Getting Started

### Prerequisites

- [n8n](https://docs.n8n.io/getting-started/installation/) installed on your system
- Basic understanding of workflow automation

### Using Workflows

1. Browse the `workflows/` directory to find a workflow that suits your needs
2. Download the `.json` file
3. In your n8n instance, go to **Workflows** → **Import from File**
4. Select the downloaded `.json` file
5. Configure the credentials and parameters as needed
6. Activate the workflow
